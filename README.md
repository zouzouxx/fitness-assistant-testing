# 健身助手 · 需求分析与测试用例库

一个对话式 AI 健身助手的需求说明书与测试用例库，配套 Python 基础练习代码（P1-P10）。

## 项目内容

- `健身助手-需求说明书.md` —— 5 大功能模块的需求拆解与边界定义（对话式产品形态 + 模块化后台）
- `健身助手-测试用例.md` —— 20 条测试用例：等价类 / 边界值 / 异常输入 / 责任型边界（含医疗安全类 P0 用例）
- `p1_student.py` ~ `p10_student.py` —— Python 练习：函数、列表、字典、字符串、类与对象、多路判断
- `p1p4_audit.py` —— 防御性测试示例：用边角料数据对 4 个函数做边界体检

## 全局数据范围（需求评审拍板）

身高 140-200cm · 体重 30-300kg · 每周训练时长 1-20 小时
